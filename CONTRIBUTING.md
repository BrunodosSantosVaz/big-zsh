# Contribuindo

Obrigado por ajudar. Este é um projeto comunitário que procura complementar o BigLinux com respeito ao trabalho original.

Antes de enviar uma mudança:

1. preserve os comandos tradicionais por padrão;
2. não copie arquivos, ícones ou marcas de terceiros para o repositório;
3. não inclua caminhos pessoais, credenciais ou dados privados;
4. mantenha a instalação reversível;
5. execute `./test-setup.sh`.

Pull requests devem explicar o problema, a solução e como a mudança foi testada. Discussões técnicas são bem-vindas; comparações depreciativas entre shells, distribuições ou comunidades não são.
